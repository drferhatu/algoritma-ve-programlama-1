## Bölüm 2 · KT1 kontrol listesi, maddeyi işaretleyerek (15 dk)

Yukarıdaki kutudaki altı maddeyi kağıda alt alta yazın ve deponuza bakarak her birinin yanına ✓ ya da ✗ koyun. ✗ olan her maddeyi **labda** kapatın; en sık eksikler şunlar:

- README'de konu adı var ama **kural cümlesi** yok: "Benim konumda ayırt edici kural şu demek: ..." cümlesini yazın.
- `0` girilince program çöküyor ya da `Gecersiz` yazıyor: `0`'ı en üstte, diğer seçeneklerden önce ele alın ve programı bitirin.
- Kural kodda var ama `if`'in içinde değil, yorum satırında anlatılmış: yorumu silmeyin, altına tek bir `if` yazın.
- `AI-BEYANI.md`'de KT1 bölümü boş: yapay zeka kullanmadıysanız bile "kullanmadım" yazın; dört satır.

Her düzeltmeden sonra `javac Uygulama.java` ve push:

```bash

git commit -m "KT1: kontrol listesi duzeltmeleri"
git push
```

Push'tan 1-2 dakika sonra deponuzun **Releases** sayfasına bakın; otomatik kontrol yalnızca iskelete bakar: derleniyor mu, iki dosya var mı, `0` ile bitiyor mu.

## Bölüm 3 · Kağıtta seçim yapıları: hata avı ve kod izleme (20 dk)

Bilgisayara dokunmadan, kağıtta. Vizenin iki soru türü tam olarak bu: "bu program ne yazar?" ve "kaç hata var, hangi satırda?". Cevaplarınızı yanınızdaki arkadaşınızla karşılaştırın; anlaşamadığınız yerde kazanan Playground'dur, ama önce kağıt.

### 3a · Kod izleme: hangi dal çalışır?

Aşağıdaki programı `puan = 85`, sonra `puan = 60`, sonra `puan = 100` için satır satır izleyin ve ekrana ne yazıldığını yazın.

```java
int puan = 85;
if (puan >= 90)
    System.out.println("AA");
else if (puan >= 80)
    System.out.println("BA");
else if (puan >= 70)
    System.out.println("BB");
else
    System.out.println("Kaldi");
if (puan >= 80)
    System.out.println("Tebrikler");
```

Soru: `puan = 100` için kaç satır çıkar; neden "AA" ile birlikte "BA" çıkmaz ama "Tebrikler" çıkar? Merdiven ile ayrı `if`'in farkını bir cümleyle yazın.

### 3b · Sarkan else

```java
int yas = 20;
boolean ogrenci = false;
if (yas >= 18)
    if (ogrenci)
        System.out.println("Ogrenci bileti");
else
    System.out.println("Cocuk bileti");
```

Girinti sizi yanıltmak için bu şekilde yazıldı. `else` hangi `if`'e aittir ve `yas = 20, ogrenci = false` için ekrana ne yazılır? Programı süslü parantezle, yazarın niyetine uygun hale getirin.

### 3c · Hata avı: durmayan asansör

Aşağıdaki programda **üç** hata var: bir sözdizimi, bir mantık, bir de "derlenir ama yanlış dal" hatası. Satır numarası ve türüyle yazın.

```java
int kat = 2;
switch (kat) {
    case 1:
        System.out.println("Zemin");
    case 2:
        System.out.println("Birinci kat");
    case 3
        System.out.println("Ikinci kat");
        break;
    default:
        System.out.println("Gecersiz");
}
if (kat = 3)
    System.out.println("Cati");
```

İpucu: Lab 5'teki durmayan asansörü hatırlayın; `break` olmadan `switch` nereye kadar akar? `=` ile `==` farkı derleyicide mi, çalışırken mi, çıktıda mı görünür?

### 3d · Kısa devre

```java
int a = 5, b = 0;
if (b != 0 && a / b > 1)
    System.out.println("Buyuk");
else
    System.out.println("Bolme yok");
```

Ne yazar ve `a / b` hiç hesaplanır mı? `&&` yerine `&` yazılsaydı ne olurdu? (Cevabı derste 5. haftada verdik; bakmadan deneyin.)
