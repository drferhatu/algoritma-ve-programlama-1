## Temel Kavramlar

- **Sözdizimi (syntax) / anlam (semantics)**: Dilden dile değişen yazım / değişmeyen algoritma.
- **Statik / dinamik tip**: Java ve C tipi baştan ister; Python çalışırken çıkarır.
- **Derleme / yorumlama**: C ve Java derlenir; Python satır satır yorumlanır.
- **Taşınabilir algoritma**: Herhangi bir dilde yazılabilen çözüm; asıl beceri budur.
- **AI beyanı**: Hangi araç, ne için, hangi kısım sizin, hangi hata yakalandı.

## Sahadan Örnekler

- Gerçek projelerde diller karışır: web arayüzü JavaScript, sunucu Java, veri analizi Python, cihaz sürücüsü C; algoritma hepsinde aynıdır.
- Kod çevirisi bugün yapay zekanın en iyi yaptığı işlerden biri; doğrulamak ise hâlâ mühendisin işi.
